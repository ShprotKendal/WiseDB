# Changelog

## 3.0.0

### Added

- C core with WikiLLM file catalog (`remember`, `read`, `edit`, `search`)
- Python `Wiki` library via Cython (no server required)
- C++ header-only wrapper (`wisedb.hpp`)
- Human CRUD: `list`, `markdown`, `update`, `delete` (C, Python, HTTP, MCP)
- Optional FastAPI server and MCP tools
- CMake install targets and pkg-config
